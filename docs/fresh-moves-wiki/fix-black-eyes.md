# Fix Black Eyes

To fix the black eyes issue you must follow these steps:

1. **UPDATE** Entity Model Features (EMF) and Entity Texture Features (ETF) to the **LATEST UPDATE**
2. If you had the AlphaSkins mod or the CustomSkinLoader mod, delete those. They are no longer needed.
3. Enter the ETF configuration menu in the resource pack menu in Minecraft (Click on the creeper face)
4. Click through these options: Textures → Player skin settings
5. Now set the "Allow skin transparency" to "All skins" by clicking it.
6. Click in the "Back" button until you quit the ETF configuration menu (The resource pack will reload, red Mojang Screen loading screen)
7. If the black eyes don't disappear. Restart the game.
